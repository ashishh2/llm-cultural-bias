# llm-cultural-bias
Quantifying and Contextualizing Cultural Bias in LLM Responses

This project investigates whether Large Language Models (specifically Gemini) exhibit cultural biases or adaptability when prompted with different cultural personas. It uses Hofstede's Cultural Dimensions Theory to analyze how the model's advice on workplace scenarios shifts when acting as a manager from different countries (e.g., Malaysia vs. Denmark for Power Distance, Japan vs. Sweden for Masculinity).
